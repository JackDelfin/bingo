# Bingo

Manual 75-ball Bingo with synchronized controller and audience displays.

See [installation](docs/INSTALL.md), [audio callouts](docs/AUDIO-CALLOUTS.md)
and [Settings](docs/SETTINGS.md). Run `bash install.sh` as your ordinary Linux
user, never with sudo. Internet is needed for a fresh installation. Existing
installations retain their database and private controller links.

The public release archive contains only reviewed source, installer inputs,
documentation and tests; it contains no Git history or installed/private state.
`release.json` inventories every other file with SHA-256.
